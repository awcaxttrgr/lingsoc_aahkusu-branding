	\chapter{Introduction}
	The style guide aims to provide a guide to writing and formatting documents written by the Executive Committee of Linguistics Society, AAHKUSU. It is part of the Society's corporate image which allows the Society's documentation to be consistent. The style guide is not legally binding, but it is strongly recommended that you follow the style guide. \par
	This style guide is for internal use only. It applies to all documents except the Constitution of Linguistics Society, AAHKUSU and any attachments to it. \par
	This style guide is heavily based on the University of Oxford Style Guide and the editorial style guide of the University of Cambridge. No copyright is claimed by this style guide. \par
	\section{Objectives of the style guide}
	We have three main objectives in writing this style guide:
		\begin{itemize}
			\item to provide an all-purpose guide to consistent presentation for the Executive Committee in written communications
			\item to review the guide at least once a year by the Executive Committee, ensuring that it properly reflects modern usage and is fit for purpose, and to update it as required
			\item as part of the review process, to invite suggestions from members of Linguistics Society who disagree with any existing guidance
		\end{itemize}
	\section{How to use this guide}
		\begin{itemize}
			\item search for a specific term (such as `dash')
			\item browse through a section (such as `capitalisation')
		\end{itemize}
	The guide does not tell you how to write. That is, even if you find an entry on `abbreviation', it does not mean you should use abbreviations everywhere. \par
	The guide is here to help you write consistently across the Society's written communications by providing a standard format. When you write, you should write with your audience and context in mind.
	\section{Rule of thumb}
	If there are multiple (correct) ways of doing something, choose the one which uses the least space and the least ink. For instance:
		\begin{itemize}
			\item close up spaces and don't use full stops in abbreviations (eg 3pm)
			\item Use lower case whenever possible
			\item Only write out numbers up to ten and use figures for 11 onwards
		\end{itemize}
	\chapter{Abbreviations, contractions and acronyms}
	Abbreviations, contractions and acronyms are used to shorten words that appear repeatedly in a long text, or they stand in for names that are more commonly known by their short form.\par
	Most of them are commonly used. However, abbreviations, contractions and acronyms specific to HKU may not be understood by everyone, so you should be careful when using them.\par
	If in doubt, you should spell the word out in full, or write them out in full at first mentioned in text, then enclose the shortened form in brackets, eg Chong Yuet Ming Amenities Centre (CYM).
	\section{General Rule}
	Don't use full stops after any abbreviations, contractions or acronyms and close up space between letters.
	\section{Abbreviations}
	These abbreviations are formed by omitting letters from the end of the word.
	{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]

			\item Professor → Prof
			\item ante  meridiem → am
			\item post  meridiem → pm
		\end{itemize} \end{mdframed} }

	\section{Contractions}
	These are formed by omitting letters from the middle of a word.
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item Mister → Mr
			\item Doctor → Dr
			\item The Reverend → The Revd
			\item Saint → St
			\item Street → St
			\item Road → Rd
			\item Building → Bldg
			\item Tower → Twr
			\item The City University of Hong Kong → CityU
			\item The Polytechnic University of Hong Kong → PolyU
			\item Linguistics Society, AAHKUSU → LingSoc	
		\end{itemize} \end{mdframed} }
	\section{Acronyms}
	These are formed from the initial letters of words (whether the result is pronounceable as a word or as a series of letters) and should be written as a single string of uppercase letters.
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item The University of Hong Kong → HKU
			\item The Chinese University of Hong Kong → CUHK
			\item International Phonetic Alphabet → IPA
			\item \textit{The Sound Pattern of English} → SPE
			\item Universal Grammar → UG
			\item Portable Document Format → PDF
		\end{itemize} \end{mdframed} }
	When using an acronym that may be unfamiliar to your readers, spell it out in full the first time it is mentioned, with the acronym following in brackets; thereafter, use the acronym alone.
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item The proposed changes are to be approved in the Constitution Review Committee (CRC). Both Arts Association, H.K.U.S.U. and HKUSU hold meetings of CRC.
		\end{itemize} \end{mdframed} }
	\section{Specific abbreviations}
		\subsection{Special use of full stops}
		Don't use full stops after any abbreviations, unless they are part of the name.
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item Mass Transit Railway → MTR
				\item The Hong Kong University Students' Union → HKUSU
				\item Arts Association, H.K.U.S.U.
			\end{itemize} \end{mdframed} }
		The name of the Society does not include any full stops.
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item Linguistics Society, AAHKUSU
			\end{itemize} \end{mdframed} }
		\subsection{Ampersands}
		Ampersands should only be used if they are part of official titles or names. Otherwise, spell out `and'.
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item Information Technology \& Teaching Task Force (IT\&T)
				\item Academic Support and Examinations Section (ASE)
			\end{itemize} \end{mdframed} }
		\subsection{Degree abbreviation}
		Use the canonical abbreviation. For a canonical list of degree abbreviations, go to \url{https://www4.hku.hk/pubunit/calendar}
		\subsection{People's initials}
		Use a space to separate each initial.
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item A N Chomsky
				\item S A Pinker
				\item D L Everett
				\item S J Matthews
				\item Yip C Y
				\item Au Yeung W H
			\end{itemize} \end{mdframed} }
		\subsection{Measurements}
		When discussing large numbers in text, it is fine to use k/m/bn as shorter ways of spelling out 1,000/1,000,000/1,000,000,000 (or writing out `one thousand'/`one million'/`one billion'), as long as you are consistent throughout the document. For multiple millions/billions you can use a mixture of words and numbers (eg 7 million, 8bn); again, ensure you are consistent throughout.
		\subsection{Latin abbreviations}
		If you use Latin abbreviations, make sure you know what they mean and when to use them. Do not use full stops after them and don't italicise them -- see the \textbf{Highlighting/emphasising} text section for when to italicise.
		\paragraph{etc} [\textit{et cetera}] -- means `and the rest'; indicates the continuation of a list
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item The Linguistics Society organises many activities: Inauguration Ceremony, Bazaar, Linguistics Festival etc [The list could continue with the other activities organised by the Linguistics Society].
		\end{itemize} \end{mdframed} }
		
		\paragraph{eg} [\textit{exempli gratia}] -- means `for example' or `such as'; use with examples which are not exhaustive (and do not follow with a comma)
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item The Linguistics Society organises many activities, eg Inauguration Ceremony, Bazaar, Linguistics Festival.\\
			\lbrack These are some, but not all, of the activities organised by the Linguistics Society\rbrack
		\end{itemize} \end{mdframed} }
				
		\paragraph{ie} [\textit{id est}] -- means `that is'; use with definitions or lists which are exhaustive (and do not follow with a comma)
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item Catch a cross-harbour bus, ie numbers 970, 970X or 973.\\
			\lbrack These are the only buses which cross the harbour\rbrack
		\end{itemize} \end{mdframed} }
		\paragraph{ibid} [\textit{ibidem}]  -- means `in the same place'; used when making a subsequent reference/citation to a publication or other source mentioned in the immediately preceding note (ie no references to anything else have appeared in between). Do not use as it is not used in APA Style.

	\chapter{Definite articles in anaphoric noun phrases}
	Very often, we shorten a proper noun to form an anaphoric noun phrase. We do this by retaining only the head noun.
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item The University of Hong Kong (antecedent)\\ → the University (anaphora)
			\item Linguistics Society, AAHKUSU (antecedent)\\ → the Linguistics Society (anaphora)\\ → the Society (anaphora)
		\end{itemize} \end{mdframed} }
		We define a term in a terminology section to clarify its meaning. Terminology sections clarify the meaning of specific terms; they do not override normal grammatical rules. It does not grant the anaphora the same grammatical properties as the antecedent.\par
		When you write, make sure the anaphoric noun phrase is grammatical.
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item The University of Hong Kong was founded in 1912. Arts, Engineering and Medicine were the three founding faculties of the University.
			\item[\xmark] The University of Hong Kong was founded in 1912. Arts, Engineering and Medicine were the three founding faculties of University.\\
			\lbrack missing determiner\rbrack
			\item Linguistics Society, AAHKUSU was founded in 1998. Promoting linguistics on HKU campus is one of the main objects of the Society.
			\item[\xmark] Linguistics Society, AAHKUSU was founded in 1998. Promoting linguistics on HKU campus is one of the main objects of Society.\\
			\lbrack missing determiner\rbrack
		\end{itemize} \end{mdframed} }
	\chapter{Capitalisation}
	Use lower case as much as possible. There is a tendency for people to capitalise words unnecessarily just because they are deemed `important'. Resist this. Company names may feature unusual capitalisation (or lack of capitalisation). Try to follow the company's convention, even if it looks ridiculous. 
		\section{General rule}
		Do \textbf{not} use a capital letter unless it is absolutely required.
		\section{Specific words}
			\subsection{Locations}
			Capitalise names of locations. Do not capitalise if it is a description of the location.
				{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
					\item The exhibition will take place on Haking Wong Podium.
					\item The booth will be set up in the area outside Bank of East Asia.
				\end{itemize} \end{mdframed} }
			\subsection{Semesters}
				Do not capitalise the word `semester'.
				{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
					\item Our Bazaar will be held in the first semester.
					\item 
					Our Orientation Camp will be held during the summer semester.
				\end{itemize} \end{mdframed} }
				If you need to abbreviate the term, use sem-1, sem-2. Do not abbreviate `summer semester'; use `summer' instead.
				{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
					\item Our Bazaar will be held in sem-1.
					\item Our Orientation Camp will be held during summer.
				\end{itemize} \end{mdframed} }
			\subsection{University}
			Capitalise when referring to The University of Hong Kong. When `university' is used in a general way, eg a place at university (meaning any university) the u should remain lowercase.\par
			Capitalise the article `The' only when referring to the University in its full name (`The University of Hong Kong'). Do not omit the article (even if the word is defined elsewhere in the text).
				{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
					\item The University of Hong Kong is an equal-opportunity employer.
					\item Candidates must satisfy the minimum requirements for entrance to The University of Hong Kong.
					\item Candidates must satisfy the minimum requirements for entrance to the University.
					\item The well-respected tertiary education institutions in Hong Kong are collectively known as `the eight universities'.
					\item She attended the Hong Kong University of Science and Technology. It's a well-respected university.
				\end{itemize} \end{mdframed} }
			\subsection{Faculty}
			Capitalise when the noun is specific, but use lowercase letters in general use. Never omit the article `the'.
				{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
					\item The Faculty of Arts is one of the founding faculties of The University of Hong Kong. The Faculty's phone number is 3917 8977.
				\end{itemize} \end{mdframed} }
			\subsection{School}
			Capitalise when the noun is specific, but use lowercase letters in general use. Never omit the article `the'.
				{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
					\item The School of Humanities is one of the many schools that make up the Faculty of Arts.
				\end{itemize} \end{mdframed} }
			\subsection{Department}
			Capitalise when the noun is specific, but use lowercase letters in general use. When referring to the Department of Linguistics, never omit the article `the', even when in the form `the Department'.
				{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
					\item The Department of Linguistics houses research in phonetics, phonology, syntax\ldots
					\item The office of the Department is on the ninth floor of Run Run Shaw Tower.
					\item The Department of Linguistics is one of the many departments under the School of Humanities.
				\end{itemize} \end{mdframed} }
			\subsection{Society}
			Capitalise only when used as part of the title of a society. When society is used in a general way, eg the constitution of a society (meaning any society) the s should remain lowercase.
				{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
					\item Linguistics Society, AAHKUSU is one of the many academic societies at HKU.
				\end{itemize} \end{mdframed} }
			Capitalise `Society' when referring to Linguistics Society, AAHKUSU. You should omit the article `the' only when referring to Linguistics Society, AAHKUSU in its full name (even if the word `Society' is defined elsewhere in the text).
				{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
					\item Linguistics Society, AAHKUSU was founded in 1998. Students who study linguistics are encouraged to join the activities organised by the Society.
					\item  Every year, many students join the activities organised by the Society.
					\item The Department of Linguistics is friends with the Linguistics Society.
				\end{itemize} \end{mdframed} }
			\subsection{Government}
			Never capitalise, whether referring to a specific country's government or the concept of a government.
				{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
					\item The current Hong Kong government is headed by Carrie Lam.
				\end{itemize} \end{mdframed} }
			\subsection{Names with prefixes}
			Follow the preference of the individual, if known; if not, use lower case for the prefix. Alphabetise by the prefix.
				{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
					\item Dick Van Dyke is a star of daytime TV.
					\item Jan van Eyck painted in the 15th century.
				\end{itemize} \end{mdframed} }
			\subsection{Professor}
				Capitalise only when used as part of an academic's formal title, not when referring to professors in general.
					{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
						\item It is common for HKU professors to publish their works in learned journals.
						\item \textit{Cantonese: A Comprehensive Grammar} is a grammar book on Cantonese authored by Professor Stephen Matthews and Professor Virginia Yip.
					\end{itemize} \end{mdframed} }
			\subsection{Reverend}
			Capitalise both `Reverend' and `The' (as well as other parts of the title).
				{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
					\item My tutor is The Reverend John Smith/The Very Reverend John Smith.
				\end{itemize} \end{mdframed} }
			\subsection{Linguistics}
			The term was mandatorily capitalised before 2018. It is no longer capitalised now. Do not capitalise `linguistics' unless it is part of the title.
				{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
					\item Many arts students study linguistics.
					\item The Linguistics Society is committed to promoting linguistics on the campus.
				\end{itemize} \end{mdframed} }
			\subsection{Names of activities organised by the Society}
			The names of the activities organised by the Society are capitalised because they are specific. When they refer to the same activities in general, or the activities organised by another society, they are not capitalised.
				{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
					\item Many societies in HKU organise bazaars throughout the year. Our Bazaar will be held from today to next Wednesday. The bazaar of Example Society will be held from next Wednesday to next Friday.
				\end{itemize} \end{mdframed} }
			\subsection{Orientation}
			Capitalise when the noun is specific, but use lowercase letters in general use.
				{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
					\item Orientation 2018
					\item Orientation Camp 2018
					\item Joint-University Orientation Day 2018
					\item Many societies organise orientation camps for freshmen of HKU.
					\item There were over 30 participants in Orientation 2018.
				\end{itemize} \end{mdframed} }
			\subsection{Executive Committee}
			Capitalise only when referring to a particular executive committee, not when referring to executive committees in general, or a proposed executive committee.
				{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
					\item Societies at HKU have their own executive committees.
					\item The Executive Committee of Linguistics Society, AAHKUSU must at least consist of four persons.
				\end{itemize} \end{mdframed} }
			\subsection{Session}
			Capitalise only as part of the Society's signature. The word should not be capitalised elsewhere.
				{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
					\item The Society session commences at the conclusion of the Annual General Meeting.
					Linguistics Society, AAHKUSU Session 2017--2018
				\end{itemize} \end{mdframed} }
			\subsection{Specifically defined terms}
			When using terms defined in a terminology section, retain the capitalisation when the terms are used in the same context. When these terms are used in a general way, do not capitalise.
				{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
					\item The Constitution of Linguistics Society, AAHKUSU defines the functions and duties of the Executive Committee. Members of the Executive Committee should familiarise themselves with the Constitution.\\
					\lbrack All these terms refer to the same thing as they do in the Constitution\rbrack
					\item There are many things that a member of an executive committee should be wary of. First and foremost, they should read the constitution of their society carefully.\\
					\lbrack All these terms refer to things in general\rbrack
				\end{itemize} \end{mdframed} }
			Do not capitalise any defined terms when the referent is `proposed'.
				{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
					\item ExampLing is the proposed executive committee of Linguistics Society, AAHKUSU. The proposed year plan will be reviewed in the Campaign Meeting tonight. Once ExampLing is elected, it will become the Executive Committee. The Executive Committee will organise the activities listed on the Year Plan of the session.
				\end{itemize} \end{mdframed} }
			If a prefix is added before such terms, capitalise the prefix, not the word.
				{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
					\item Non-members
				\end{itemize} \end{mdframed} }
			\section{Titles}
				\subsection{People}
				See \textbf{Names and titles} for details.
				\subsection{Books/films/songs/games etc}
				Capitalise the first word of the title, and all words within the title except function words eg articles (a/an/the), prepositions (to/on/for etc) and conjunctions (but/and/or etc). 
					{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
						\item \textit{Ip Man 2}
						\item \textit{Gone with the Wind}
						\item \textit{Grand Theft Auto V}
						\item `Always Look on the Bright Side of Life'
					\end{itemize} \end{mdframed} }
				\newpage
				\subsection{Subtitles}
				Capitalise subtitles only if the original title is printed that way.
					{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
						\item \textit{The Tale of Samuel Whiskers, or The Roly-Poly Pudding}
						\item \textit{Dr Strangelove or: How I learned to Stop Worrying and Love the Bomb}
					\end{itemize} \end{mdframed} }
				\subsection{Headlines, journal articles, chapter titles and lecture titles}
				Only capitalise the first word, any proper nouns and the first word following a full stop/question mark/exclamation mark.
					{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
						\item `Who speaks for climate? Making sense of media reporting on climate change'
						\item Rock rafts could be `cradle of life'
						\item `Multiplicity of data in trial reports and the reliability of meta-analyses: empirical study'

		\chapter{Numbers}
			\section{How to write numbers}
			Spell out whole-number words for one to ten; use figures for numbers above ten.
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item There were two people in the queue ahead of me, and six behind me.
				\item I need to buy Christmas presents for 12 people this year.
				\item 這次會議總共有六人出席。
				\item 我們的活動總共有 25 人參加。
			\end{itemize} \end{mdframed} }
			Use a combination of a figure and a word for very large round numbers (such as multiple millions/billions etc), or abbreviate it to `m', `bn' etc.
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item The population of the earth is now 7 billion people.
				\item The population of the earth is now 7bn people.
				\item Last time the organisation spent \$2m.
			\end{itemize} \end{mdframed} }
			If there are a lot of figures in a paragraph or text, some above ten and some below, use figures throughout to allow easy comparison by readers.
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item  There were 2 people in the queue ahead of me, and 22 behind me. The queues for other advisors had 10, 3 and 12 people.
				\item 今天有 6 人缺席會議，而星期一至三分別有 10 、13 及 20 人缺席。
			\end{itemize} \end{mdframed} }
			Spell out words for `first', `second' and so on up to and including `tenth'; use numbers and `st'/ `nd'/ `rd'/ `th' for larger ordinal numbers. Don't use superscript (to prevent problems with line spacing).
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item She was the first person from her school to get a place at HKU.
				\item He got an upper second, to his relief.
				\item[\xmark] She got a 3rd class degree.
				\item The 17th president of the United States was Andrew Johnson.
			\end{itemize} \end{mdframed} }
			Always use figures and symbols for percentages, measurements and currency. Use commas to punctuate large numbers. Close up spaces between the number and the unit.
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item  Participation is worth 25\% of the available marks.
				\item[\xmark] 20 percent of the commuters use their cars.
				\item The Pillar of Shame is 8m tall.
				\item The cost, at \$600, was less than the overall budget of \$550.
				\item The population of New York City is estimated to be 8,008,278.
			\end{itemize} \end{mdframed} }
			\subsection{Times}
			Use either the 12- or 24-hour clock -- not both in the same text. Both 12-hour clock and the 24-hour clock use a colon between the hours and minutes, but the 24-hour clock omits am/pm.
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item The activity starts at 11:30am and ends at 1pm.
				\item The activity starts at 11:30 and ends at 13:00.
				\item[\xmark] The activity starts at 11:30am and ends at 13:00
				\item[\xmark] The lecture starts at 16:00pm.
			\end{itemize} \end{mdframed} }
			Use `noon' or `midnight' instead of `12', `12 noon' or `12 midnight'.
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item The closing date for applications is noon on 12 July.
			\end{itemize} \end{mdframed} }
			Consider using 11:59pm or 23:59 for deadlines around midnight to avoid ambiguity.
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item The closing date for application is 23:59 on 12 July.
			\end{itemize} \end{mdframed} }
			If using the 12-hour clock, don't use additional `:00' for times on the hour, and close up space between the number and the `am' or `pm'.
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item The activity starts at 9am.
				\item The activity starts at 11:30am and ends at 1pm.
				\item[\xmark] The activity starts at 9:00am.
				\item[\xmark] The activity starts at 9 am.
			\end{itemize} \end{mdframed} }

			\subsection{Dates}
			Always put the date before the month.
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item Easter this year is on 21 April.
				\item[\xmark] Easter this year is on April 21.
			\end{itemize} \end{mdframed} }
			Don't use `th' etc with dates -- just the number and month -- and never precede the number with `the'.
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item Easter this year is on 21 April.
				\item[\xmark] 11th November is Remembrance Day this year.
				\item[\xmark] Remembrance Day this year is on the 11 November.
			\end{itemize} \end{mdframed} }
			Use days with dates only for emphasis or the avoidance of confusion/ambiguity. 
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item The wedding is on 30 December.
				\item[\xmark] The wedding is on Saturday 20 December.
				\item The Modern Superstitions conference is on Friday 13 April.
				\item You must submit your draft on 13 November.
				\item You must submit your assignment on or before Sunday 15 November. We will discuss the answers on Monday 16 November.
			\end{itemize} \end{mdframed} }
			\subsection{Spans of numbers and years}
			Shorten periods where it is not ambiguous to do so and use the shortest text possible. However, do not elide numbers between 11 and 19, which must always be written in full (as they would be spoken).
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item The `short twentieth century' refers to the period 1914--91.
				\item The First World War (1914--18) was shorter than the Second World War (1939--45).
				\item[\xmark] The First World war lasted from 1914--8.
				\item The professorship was held 1993--5 by Alice Jenkins.
				\item[\xmark] Inner-city flats cost \$100--\$200,000.  [Price could start at \$100 or \$100,000.]
			\end{itemize} \end{mdframed} }
			To refer to an academic or financial year, use an n-dash (`2018--2019', `2018--19'). Do not shorten the session span in the name of the Society.
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item The Executive Committee Members for the upcoming session of office will be elected in the first semester of the 2018--19 academic year.
				\item Linguistics Society, AAHKUSU Session 2018--2019
			\end{itemize} \end{mdframed} }
			If using `from' with a start date/time, always use `to' to indicate the end date/time rather than an n-dash; alternatively, just use an n-dash without `from'.
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item Linguistics Festival will be held from 26 Mar to 13 Apr.
				\item Linguistics Festival will be held 26 Mar--13 Apr.
				\item[\xmark] Linguistics Festival will be held from 26 Mar--13 Apr.
			\end{itemize} \end{mdframed} }
			\subsection{Date as part of the name}
			The date of a Session of the Society goes after the name.
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item Linguistics Society, AAHKUSU Session 2017--2018
				\item 香港大學學生會文學院學生會語言學學會二零一七至二零一八年度
			\end{itemize} \end{mdframed} }
			If adding a year to a name of an activity, the year can go before or after the name, provided you use them consistently.
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item 	Linguistics Festival 2018
				\item Orientation 2018
			\end{itemize} \end{mdframed} }

		\chapter{Punctuations}
		\section{General rule}
		Use as little punctuation as necessary while retaining the meaning of the sentence.
		\section{Apostrophe}
			\subsection{To indicate possession}
			Use \textbf{'s} after singular nouns, plural nouns which do not end in s and indefinite pronouns.
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item Jack's book
				\item anybody's guess
				\item the children's play area is next to the men's toilet.
			\end{itemize} \end{mdframed} }
			Use just \textbf{'} after plural nouns ending in s.
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item Strong tea is sometimes called builders' tea.
			\end{itemize} \end{mdframed} }
			If a name already ends in \textbf{s} or \textbf{z} and would be difficult to pronounce if \textbf{'s} were added to the end, consider rearranging the sentence to avoid the difficulty.
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item Jesus's methods were unpopular with the ruling classes.
				\item[OR \cmark] The methods of Jesus were unpopular with the ruling classes.
			\end{itemize} \end{mdframed} }
			\newpage
			In compound nouns and where multiple nouns are linked to make one concept, place the apostrophe at the end of the final part (and match it to that noun).
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item the Archbishop of Canterbury's tortoise
				\item my mother-in-law's dog
				\item Lee and Herring's \textit{Fist of Fun}
			\end{itemize} \end{mdframed} }
			Do not use an apostrophe in its with the meaning `belonging to it' (this is analogous with his/hers/theirs): note that \textbf{it's} is a contraction of `it is'.
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item The cat has been out in the rain and its paws are muddy.
				\item The cat has been out in the rain and it's muddy.
				\item[\xmark] The cat has been out in the rain and it's tail is wet.
			\end{itemize} \end{mdframed} }
			Some names have an apostrophe and some don't -- this can't be predicted and must be checked. Some street names have an apostrophe (usually linked to saints' names from nearby organisations or churches); these are also idiosyncratic.
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item Rennie's Mill
				\item King's Park
				\item Belcher's Street
				\item Gilman Street
				\item Gilman's Bazaar
				\item St Joseph's Path
				\item St John's Lane
				\item St. John's College
			\end{itemize} \end{mdframed} }
			Use apostrophes with noun phrases denoting periods of time (use an apostrophe if you can replace the apostrophe with `of').
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item He took a week's holiday [holiday of a week].
				\item You must give three months' notice [notice of three months].
			\end{itemize} \end{mdframed} }
			But do not use an apostrophe in adjectival phrases.
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item She was eight months pregnant when she went into labour.
			\end{itemize} \end{mdframed} }
		\newpage
			\subsection{To indicate that letters have been omitted (contractions)}
			Use an apostrophe in the position the omitted letters would have occupied, not where the space was between the original words.
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item I don't like cheese. [ = do not]
				\item[\xmark] I do'nt like cheese. [≠do not]
				\item He wouldn't do that.
			\end{itemize} \end{mdframed} }
			Do not use an apostrophe before contractions accepted as words in their own right.
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item He is on the phone.
				\item He had swine flu.
				\item[\xmark] There is no vaccine for all types of `flu.
			\end{itemize} \end{mdframed} }
			Do not use an apostrophe to make a plural, even with a word/phrase that is not usually written in the plural or which appears clunky. All of the following examples take an \textbf{s} as normal in English to make their plurals.
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item[\xmark] Three video's for a tenner.
				\item[\xmark] I trust all the MP's.
				\item[\xmark] Clothes were colourful in the 1970's.
				\item[\xmark] CD's will soon be obsolete.
				\item[\xmark] This is a list of do's and don't's.
			\end{itemize} \end{mdframed} }
			To clarify something which will look odd if an \textbf{s} is added, consider italicising it or placing it in single quotation marks.
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item Subtract all the \textit{x}s from the \textit{y}s.
				\item Dot the `i's and cross the `t's.
			\end{itemize} \end{mdframed} }
			\section{Brackets}
			\subsection{Round brackets ( )}
			Use in place of a pair of dashes or commas around a non-defining phrase (one which adds extra information, a translation, dates, an explanation or a definition).
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item The Main Building (which was built in 1912) needs to be repaired.
				\item It was (as far as I could tell) the only example of its kind.
				\item Swire Building (built in the 1980s) has only one lift.
				\item The tactic of Blitzkrieg (which means `lightning war' in German) was used in the invasion of Poland in 1939.
				\item Preheat the oven to 350°F (180°C).
			\end{itemize} \end{mdframed} }
			\subsection{Using other punctuation with brackets}
			Include full stops/exclamation marks/question marks/quotation marks before the closing bracket only if the complete sentence/quote is in brackets; otherwise, punctuate after the closing bracket.
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item The last bus today is at 16:45 (which is earlier than usual).
				\item The last bus today is at 16:45. (That's earlier than usual.)
			\end{itemize} \end{mdframed} }
			\subsection{Square brackets [ ]}
			Use to enclose comments, corrections, references or translations made by a subsequent author or editor.
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item An article referring to the restrictions placed by some airlines on the appearance of female cabin crew stated that even footwear was proscribed [sic].
				\item I have been responsible in the real sense, that I have had the blame for everything that has gone wrong. [Laughter and cheers.]
				\item This was quoted by Brown [1940, Chicago].
			\end{itemize} \end{mdframed} }
			Also use to contain narrow phonetic transcriptions.
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item[\cmark] {\andika [kʰæʔ]}
			\end{itemize} \end{mdframed} }
			\subsection{Angle brackets < > and curly brackets \{ \}}
			These are used for technical purposes -- only use them in the correct context. 
			Use mathematical angle brackets to contain orthography.
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item[\cmark] {\andika [kʰæʔ]} $\langle$cat$\rangle$
				\item[\xmark] {\andika [kʰæʔ]} <cat>
			\end{itemize} \end{mdframed} }
			\section{Bullet points}
			Don't use hyphens in place of bullet points in the first level of the list.
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item  \begin{itemize}[label=\bullet]
					\item item 1
					\item item 2
				\end{itemize} 
			\end{itemize} \end{mdframed} }
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item[\xmark]  \begin{itemize}[label=-]
					\item item 1
					\item item 2
				\end{itemize}
			\end{itemize} \end{mdframed} }
		\newpage
		Don't punctuate the end of bullet points which are a list of items.
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item Early benefactors of the University \begin{itemize}[label=\cmark]
				\item[$\bullet$] Loke Yew
				\item[$\bullet$] Mody
				\item[$\bullet$] Sir Cecil Clementi
			\end{itemize} 
		\end{itemize} \end{mdframed} }
		If the bullet points form a complete sentence with preceding text, add a full stop to the end of the last point.
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item The early benefactors of the University include: \begin{itemize}[label=\bullet]
				\item Loke Yew
				\item Mody
				\item Sir Cecil Clementi.
			\end{itemize}
		\end{itemize} \end{mdframed} }
		If text inside the bullet point is a complete sentence in its own right, add a semicolon to the end of each point, `or' or `and' (depending on the sense of your sentence) to the end of the penultimate point, and a full stop to the end of the last one.
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item The following will be considered good reasons for missing the final meeting of the year: \begin{itemize}[label=\bullet]
				\item there was a postal strike. This only applies if the postal strike took place before the date of the meeting and if you have not signed up for email alerts;
				\item you are absent as a result of illness;
				\item you are unable to attend because of problems with public transport (proof of this will be required);
				\item there is something more interesting happening elsewhere which you would rather attend; or
				\item you have obtained a ticket to see Dayo Wong's stand-up comedy.
			\end{itemize} 
		\end{itemize} \end{mdframed} }
		\section{Colon and semicolon}
			Use a colon to introduce a subclause which follows logically from the text before it, is not a new concept and depends logically on the preceding main clause.
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item When I was young, I went on two holidays: to the Lake District and to Cornwall.
				\item A new drink was born in Hong Kong: Yuenyeung.
			\end{itemize} \end{mdframed} }
			Do not use a colon if the two parts of the sentence are not logically connected.
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item[\xmark] I used to be slim: I will try to lose weight.
				\item I would like to be slim: I will try to lose weight.
				\item[\xmark] We were in trouble this time: we'd never been in trouble before.
				\item We were in trouble this time: the lid had come right off.
				\item There are two parts to this sentence: the first part, which precedes the colon, and the second part, which doesn't.
			\end{itemize} \end{mdframed} }
			Use a semicolon to link two related parts of a sentence, neither of which depends logically on the other and each of which could stand alone as a grammatically complete sentence.
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item The best job is the one you enjoy; the worst job is the one you hate.
				\item It is a far, far better thing that I do, than I have ever done; it is a far, far better rest that I go to, than I have ever known.
			\end{itemize} \end{mdframed} }
			Use semicolons in place of commas in a complicated list or sentence if it will improve clarity, particularly if list items already include commas.
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item We plan to review the quality of the research of the department, including its participation in interdepartmental, interdivisional and interdisciplinary activities; its research profile and strategy; and future challenges and opportunities.
				\item I visited the Ashmolean Museum, Oxford; the Victoria and Albert Museum, London; and the Pencil Museum, Keswick.
			\end{itemize} \end{mdframed} }
		\section{Comma}
		Use a pair of commas to surround a non-defining clause (one which adds descriptive information but which can be removed without losing the meaning of the sentence) -- note that only `which' or `who' can be used in this type of clause, not `that'.
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item The Main Building, which was built in 1912, needs to be repaired.
			\item The man, who climbed the tower without a safety harness, died of old age.
		\end{itemize} \end{mdframed} }
		Do not use commas to surround a defining clause (which cannot be removed without losing the meaning of the sentence) -- note that `which' or `who' can be replaced by `that' in this type of clause.
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item The building which was built in the 1910s needs to be repaired [but the building which was built in the 1920s does not].
			\item The man that climbed the tower without a safety harness died of old age [but the other man died in a different way].
			\item He asked his friend Sam to be his second [not any of his other friends].
		\end{itemize} \end{mdframed} }
	\newpage
		Use commas to surround a non-defining word or phrase (which adds information but could be omitted without changing the sense of the sentence), and follow the non-defining word/phrase with a single comma if it is at the start of the sentence.
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item Shakespeare, the prolific playwright, might not have existed.
			\item A prolific playwright, Shakespeare might not have existed.
			\item He asked Sam, his friend, to be his second [not the Sam who is his barber].
			\item The Chief Executive, Carrie Lam, is an alumna of the University.
		\end{itemize} \end{mdframed} }
		Do not use a comma where defining information is used at the start of a sentence.
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item The prolific playwright Shakespeare might not have existed.
			\item[\xmark] The prolific playwright, Shakespeare might not have existed.
			\item His friend Sam was his second.
			\item[\xmark] His friend, Sam was his second.
		\end{itemize} \end{mdframed} }
		\subsection{Defining vs non-defining information}
		Do not use a comma to join two main clauses, or those linked by adverbs or adverbial phrases (eg `nevertheless', `therefore', `however'). This is sometimes referred to as `comma splicing'. Either use a semicolon or add a coordinating conjunction (eg `and', `but', `so').
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item Shakespeare was popular, and his plays were all profitable.
			\item Shakespeare was popular; his plays were all profitable.
			\item[\xmark] Shakespeare was popular, his plays were all profitable.
		\end{itemize} \end{mdframed} }
		Use a comma after an introductory adverb, adverbial phrase or subordinate clause; or use a pair of commas surrounding it if it is in the middle of a sentence.
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item However, it was too late for that.
			\item It was, however, too late for that.
			\item With his possessions in a bundle, Dick Whittington walked to London.
			\item Dick Whittington, with his possessions in a bundle, walked to London.
		\end{itemize} \end{mdframed} }
		Do not use a comma after a time-based adverbial phrase.
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item After playing tennis all day she was tired.
			\item Whenever she went to the cinema she ate popcorn.
			\item In 2010 the most popular game among children was hopscotch.
		\end{itemize} \end{mdframed} }
	\newpage
		Use a comma between multiple qualitative adjectives (those which can be used in the comparative/superlative or modified with `very', `quite' etc).
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item He was a big, fat, sweaty man with soft, wet hands.
		\end{itemize} \end{mdframed} }
		Do not use a comma between multiple classifying adjectives: absolutes which either are or are not, such as `unique', `English', `black' etc (although note that stylistically these can be modified).
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item It was an edible German mushroom.
			\item The eighteenth-century sandstone tower is lit up at night.
		\end{itemize} \end{mdframed} }
		Do not use a comma between classifying and qualitative adjectives.
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item It was a large German mushroom with hard black edges.
			\item It was a large, squishy German mushroom with hard, frilly black edges.
		\end{itemize} \end{mdframed} }
		Use a comma between items in a list.
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item I ate fish, bread, ice cream and spaghetti.
			\item I have nothing to offer but blood, toil, tears and sweat.
		\end{itemize} \end{mdframed} }
		Note that there is no comma between the penultimate item in a list and `and'/`or', unless required to prevent ambiguity -- this is sometimes referred to as the `Oxford comma'. However, always insert a comma in this position if it would help prevent confusion.
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item[\xmark] He took French, Spanish, and Maths A-levels.
			\item I ate fish and chips, bread and jam, and ice cream.
			\item We studied George III, William and Mary, and Henry VIII.
			\item[\xmark] She left her money to her parents, Mother Theresa and the pope.
		\end{itemize} \end{mdframed} }
	\subsection{Society Signature}
	The legal name of the Society includes a comma. When the legal name is presented in text, the legal name must be written in one line and the comma must be presented.
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item Linguistics Society, AAHKUSU
		\end{itemize} \end{mdframed} }
	In email signatures, the name can be split into two lines, but the comma remains.
	{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
		\item Linguistics Society,\\
		AAHKUSU
	\end{itemize} \end{mdframed} }
	\newpage
	In case the name does not occur in text, rather as a separate graphic element, the comma can be replaced by a line break for stylistic purposes.
	{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
		\item Linguistics Society\\
		AAHKUSU\\
		LATEST EXAMPLE ACTIVITY!\\		
		We at Linguistics Society, AAHKUSU are proud to present our latest activity -- Example!
	\end{itemize} \end{mdframed} }
	\section{Dashes and hyphens --- -- -}
		\subsection{m-dash (---)}
		Do not use; use an n-dash instead.
		\subsection{n-dash (--)}
		To type an n-dash,
			\begin{itemize}
				\item type \texttt{option + hyphen} on a Mac
				\item type \texttt{alt + numpad 0151} on a Windows
				\item type two hyphens \texttt{(--)} in {\fontfamily{cmr}\selectfont \LaTeX}.
			\end{itemize}
		Use in a pair in place of round brackets or commas, surrounded by spaces.
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item It was -- as far as I could tell -- the only example of its kind.
				\item The Main Building -- which was built in the 1910s -- needs to be repaired.
			\end{itemize} \end{mdframed} }
		Use singly and surrounded by spaces to link two parts of a sentence, in place of a colon.
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item The bus was late today -- we nearly missed the lecture.
			\end{itemize} \end{mdframed} }
		Use to link concepts or ranges of numbers, with no spaces either side.
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item German--Polish non-aggression pact
				\item The salary for the post is \$25,000--\$30,000.
				\item Radio 1 is aimed at the 18--25 age bracket.
			\end{itemize} \end{mdframed} }
		Use between names of joint authors/creators/performers etc to distinguish from hyphenated names of a single person.
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item Lennon--McCartney compositions
				\item Superman--Batman crossover comics
			\end{itemize} \end{mdframed} }
		\subsection{Hyphen (-)}
			\subsubsection{When to use a hyphen}
			In an adjectival phrase before a noun
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item the up-to-date list
				\item The value of a first-class degree is indisputable.
				\item a hot-air balloon
				\item `Rethinking provincialism in mid-nineteenth-century narrative fiction: Villette from our village'
			\end{itemize} \end{mdframed} }
		In an adjectival phrase including a verb participle
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item The jumper was tight-fitting.
		\end{itemize} \end{mdframed} }
		With prefixes only if required to avoid confusion/mispronunciation, such as where prefixes themselves or letters are repeated
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item predynastic Egypt
			gifts of pre-eminent objects and works of art to the nation
			\item The animals are re-released into the wild when recovered.
			\item A protein precursor can also be called a pro-protein.
			\item Procapitalists and anticapitalists clashed in the streets.
			\item The email address for the webmaster can be found on the website.
		\end{itemize} \end{mdframed} }
		With prefixes before a proper name, number or date
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item anti-Thatcherism
			\item pre-2000 politics
			\item Midterms start in mid-October.
		\end{itemize} \end{mdframed} }
		In numbers which are spelt out
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item Twenty-seven is the most popular `random' number.
			\item \textit{The Thirty-Nine Steps}
		\end{itemize} \end{mdframed} }
		In compass points (unless used geographically rather than as directions)
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item They're heading south-east.
			\item nor'-nor'-east
			\item The southwest is a popular holiday destination.
		\end{itemize} \end{mdframed} }
		\subsubsection{When not to use a hyphen}
		In noun phrases
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item distance learning
			\item The 19th century saw much reform.
		\end{itemize} \end{mdframed} }
		To make a new compound noun -- if it is a recognisable concept, make it one word; if it isn't, use two words.
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item Websites are made up of webpages.
			\item Send me an email when you're ready to proceed.
			\item[\xmark] Send me an e-mail.
		\end{itemize} \end{mdframed} }
		In an adjectival phrase following a noun
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item The list was up to date.
			\item His marks just scraped into the first class.
			\item She wasn't top-drawer.
		\end{itemize} \end{mdframed} }
		In an adjectival phrase before a noun where the first element is an adverb ending in \mbox{‑ly} (but note that any other adverbs in adjectival phrases do take a hyphen)
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item She had a finely tuned ear for off-key music.
			\item XML documents must be well-formed texts.
			\item[\xmark] She was a highly-respected tutor.
			\item She was a badly paid apprentice.
		\end{itemize} \end{mdframed} }
	\section{Ellipsis (\textellipsis)}
		Use an ellipsis to show that some text is missing, usually from a quotation -- do not surround it with spaces.
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item we shall fight on the beaches\textellipsis we shall never surrender\textellipsis 
			\item It is a truth universally acknowledged\textellipsis 
		\end{itemize} \end{mdframed} }
		There is no need to add square brackets around an ellipsis.
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item[\xmark] [\textellipsis ]we shall fight on the beaches[\textellipsis ]
		\end{itemize} \end{mdframed} }
	\newpage
		Use an ellipsis to indicate a pause for comic or other effect -- follow the ellipsis with a space in this case, as it stands in place of a comma or full stop.
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item You don't have to be mad to work here\textellipsis \space but it helps!
		\end{itemize} \end{mdframed} }
		Note that, if used either in place of omitted text at the end of a clause/sentence or to indicate a pause for effect, a full stop/comma should not follow the ellipsis. However, an exclamation mark or a question mark can and should follow the ellipsis if required.
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item Are you\textellipsis ?
			\item Did he say that\textellipsis ?
		\end{itemize} \end{mdframed} }
		Use an ellipsis to indicate a trailing off in speech or thought.
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item We could do this\textellipsis or maybe that\textellipsis 
		\end{itemize} \end{mdframed} }
	\section{Full stop, exclamation mark and question mark}
	Use one -- but only one -- of these at the end of every sentence.
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item What time did you leave last night?
			\item We went home at 5 o'clock.
			\item Go home now!
		\end{itemize} \end{mdframed} }
	Do not use a full stop at the end of titles, even if they make a sentence, but, if a title ends with an exclamation mark or question mark, do include it.
	{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
		\item \textit{All's Well that Ends Well} is my favourite play.
		\item `Will You Still Love Me Tomorrow?' was a hit for the Shirelles.
		\item `Help!' was covered by Bananarama in 1989.
	\end{itemize} \end{mdframed} }
	Do not use a full stop if it will be followed, or preceded, by an ellipsis.
	{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
		\item[\xmark] Behind him stood a figure. \textellipsis It was ghostly grey.
	\end{itemize} \end{mdframed} }
	Use a full stop, not a question mark, at the end of a reported question -- only use a question mark for a direct question (whether in quotation marks or not).
	{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
		\item He asked if I wanted to go home that morning.
		\item `Do you want to go home this morning?' he asked.
		\item[\xmark] He asked if I wanted to go home?
	\end{itemize} \end{mdframed} }
	\newpage
	Use a full stop, not an exclamation mark, at the end of a reported imperative.
	{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
		\item Wait for me!\\ → He asked me to wait for him.
	\end{itemize} \end{mdframed} }
	\section{Quotation marks}
	Use single quotation marks for direct speech or a quote, and double quotation marks for direct speech or a quote within that.
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item `I have never been to Norway,' he said, `but I have heard it described as ``the Wales of the North''.'
		\end{itemize} \end{mdframed} }
	Use no quotation marks if the quote is displayed (ie not in line with the rest of the text).
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item as I noted then,
			\begin{itemize}
				\item[] 
				Those of us who toil in the Groves of Academe know full well that our research helps inform our teaching\textellipsis 
			\end{itemize} 
		\end{itemize} \end{mdframed} }
	Use single quotation marks and roman (not italic) type for titles that are not whole publications: eg short poems, short stories, songs, chapters in books, articles in periodicals etc. See also \textbf{Highlighting/emphasising} text.
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item \textit{I, Robot} contains nine short stories, of which `Little Lost Robot' is my favourite. 
			\item Queen's `Bohemian Rhapsody', from the album \textit{Night at the Opera}, reached number one in both 1975 and 1991.
		\end{itemize} \end{mdframed} }
	\subsection{Using other punctuation with quotation marks}
	If the quote would have required punctuation in its original form, place the punctuation inside the quotation marks. (If it is unclear, try writing the whole sentence out without quotation marks and `he said' etc, and replicate the resulting punctuation.)
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item Bob likes cheese.\\ →  `Bob', I said, `likes cheese.' OR\\
			`Bob likes cheese,' I said.
			\item Bob, do you like cheese?\\ → `Bob,' I asked, `do you like cheese?'
			\item Out, damn'd spot!\\ →  `Out,' said Lady Macbeth, `damn'd spot!'
			\item `You're engaged to Florence?' I yipped, looking at him with a wild surmise.
		\end{itemize} \end{mdframed} }
	\newpage
	Place any punctuation which does not belong to the quote outside the quotation marks (except closing punctuation if the end of the quote is also the end of the sentence).
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item After all, tomorrow is another day.\\
			 → `After all,' said Scarlett, `tomorrow is another day.' OR \\
			 `After all, tomorrow', said Scarlett, `is another day.'
			\item[\xmark] `The kitchen,' he said, `is the heart of the home'.
			\item `The kitchen', he said, `is the heart of the home.'
		\end{itemize} \end{mdframed} }
	Note that American English has different rules about the use of quotation marks.
	
	\chapter{Names and titles}
		\section{Aliases}
		Chinese names are transcribed phonetically in English, eg CHAN Tai Man. Many will choose an English alias for use in daily conversation, eg Peter.\par
		When referring to a Chinese name in English, follow the official name verbatim. The official name is the name shown on personal identification documents, the name shown on a student registration card/staff card, or the name stored in the Student Information System (SIS). Write the surname in uppercase.
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item  CHAN Tai Man
		\end{itemize} \end{mdframed} }
		If a person has an English alias, you can add it after their official name, separating them with a comma.
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item CHAN Tai Man, Peter
		\end{itemize} \end{mdframed} }
		In cases where the name must match the official name, do not add an alias.
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item Name of student: CHAN Tai Man
		\end{itemize} \end{mdframed} }
		If the English name is part of the person's official name, do not add a comma. Follow the name verbatim.
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item CHEUNG Sam Sammy
		\end{itemize} \end{mdframed} }
	\newpage
		\section{General titles}
		Use capitals for titles prefixing names, but not for job descriptions. Note that some job descriptions are never used with names, such as `prime minister'.
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item Although being president of the United States is stressful, President Obama was glad to be re-elected.
			\item The prime minister of Great Britain and Northern Ireland is the leader of the party that wins the most seats. The Right Honourable Theresa May MP is the current prime minister.
			\item The current pope, Pope Francis, is Argentine.
		\end{itemize} \end{mdframed} }
		Give people's title, forename and surname when first mentioned. On subsequent mentions, use either surname only or title and surname (unless further information is required to prevent ambiguity), but be consistent with whichever usage you choose.
	{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
		\item Dr John Smith was present at the ceremony, as was Professor Susan Jones. Dr Smith had to leave early.
		\item Dr John Smith and Professor Susan Jones presented their research paper to a large audience. The results will be published in book form, which Smith says will be available in the spring.
		\item[\xmark] Dr John Smith and Professor Susan Jones debated the topic. Smith recently reviewed Professor Jones's book.
	\end{itemize} \end{mdframed} }
	Note that it can be helpful to your readers to clarify the sex of the person if it is unclear (eg if they have a name given to men and women, or an unusual name).

	\section{Other titles}
	In formal contexts, you may need to include other titles of an individual. Depending If an individual has expressed a wish to be addressed in a particular way, even if it is technically incorrect, use their preferred style.\par
	\newpage
	For someone entitled to a styling such as Sir/Dame as well as an academic title, the academic title always precedes the Sir/Dame if both are used.
	{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]

		\item Professor Dame Susan Jones
		\item[\xmark] Sir Professor John Smith
	\end{itemize} \end{mdframed} }

		\item The Revd Professor Andrew Linzey
		\item[\xmark] Dr Revd Giles Fraser
	\end{itemize} \end{mdframed} }

Note that non-academic titles should not be used with surnames only and that `The Revd' should not be used with surnames alone; revert to Dr/Mr/ Miss/Mrs as appropriate.

		\item Sir John
		\item Professor Jones
		\item Dr Fraser
		\item[\xmark] The Revd Fraser
		\item[\xmark] Revd Professor Linzey

Dr Precise and Sir John are both senior members of the University Tiddlywinks Club, and Dr Precise is the author of the bestselling \textit{Pedantry and Hypothetical Names}. He is not to be confused with his colleague, The Revd Bona-Exempla Familyname. Miss Familyname will give her lecture next week.

	\subsection{Postnominals}
	Remember that you do not need to list all awards, degrees, memberships etc held by an individual -- only those items relevant to your writing.\par
	The order for postnominals is:
	\begin{enumerate}
		\item civil honours
		\item military honours
		\item SC/QC
		\newpage
		\item degrees, in the order
		\begin{enumerate}
			\item bachelors'
			\item masters'
			\item doctorates
			\item postdoctoral
		\end{enumerate}
		\item diplomas
		\item certificates
		\item membership of academic or professional bodies.
	\end{enumerate}
	Do not include a BA for Oxford/Cambridge graduates if they also have the MA.
	\subsection{Academic qualifications}
	Consider giving the name of the awarding university, using a shortened form if required and if easily recognisable (Oxf, Camb, UCL, MIT etc) if academic qualifications are relevant. Abbreviations of Latin origin (eg Oxen, Cantab) should be used sparingly.\par
	A space is used to separate degrees from the same institution, and a comma is used to separate sets of degrees from different institutions; if the same level degree has been awarded by more than one institution, list them in alphabetical order of institution.
	{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]

		\item Sir Charles Overlord, VC, BA S'ton
	\end{itemize} \end{mdframed} }
	\chapter{Highlighting/emphasising text}
		\section{Bold}
		Use bold sparingly to emphasise the part of your text you wish to stand out. This could be someone's name, a deadline date or another key piece of information.\par
		Punctuation which follows bold text should not itself be bold (unless the whole sentence is in bold type).\par
		If you are transcribing a speech, you might want to use bold text (or italic text) to emphasise words in writing on which the speaker placed particular emphasis in speech.
		{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
			\item The train station was officially named \textbf{Sung Wong Toi}.
			\item Applications can either be made online or emailed to\\ \texttt{sample@email.com}. The deadline for submissions is \textbf{noon on 2 April} and any applications received later than this will not be considered.
		\end{itemize} \end{mdframed} }
		\section{Italic}	
		Use italics to flag part of your text which is different from that surrounding it.\par
		Titles of books, journals, plays, films, musical works etc should be given in italics if they are a complete published work; if you are referring to an individual short story, song, article etc within a larger publication, use single quotation marks (see also \textbf{Quotation marks} under \textbf{Punctuation}).
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item \textit{I, Robot} contains nine short stories, of which `Little Lost Robot' is my favourite.
				\item The number-one single in the hit parade this week is `Candy' by Robbie Williams, from the album \textit{Take The Crown}.
			\end{itemize} \end{mdframed} }	
		If the title includes `The' or `A' as the start of the title, italicise that as well.
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item \textit{A Tale of Two Cities} has perhaps the most famous opening sentence in English literature.	
			\end{itemize} \end{mdframed} }	
		\newpage
		Use italics for foreign words and phrases embedded within your text, including species and genera names in Latin.
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item There are nine \textit{ex officio} members in the Council.
				\item When producing its annual report, the committee shall consider, \textit{inter alia}, any relevant HEFCE evaluations.

			\end{itemize} \end{mdframed} }
		Plurals, past tenses or other grammatical changes to italicised titles or phrases should only be italicised up to the end of the title or phrase -- do not italicise the \textbf{s}, \textbf{ed} etc -- and punctuation should only be italicised if it is part of the title, quote etc. Note that it is not always easy to tell whether a full stop/comma is in italic.

			\section{Common confusions in word usage}
			 {\small 
			 	\renewcommand*{\arraystretch}{1.8}
			 	\begin{longtable}{p{1.5cm} | p{4.75cm} | p{4.75cm}}
			 		\toprule
			 		\textbf{Confused words} &\textbf{How they differ} & \multicolumn{1}{l}{\textbf{Example}} \\
			 		\midrule
			 		
					\noindent \mbox{among} vs \mbox{between} &
					\begin{itemize}[noitemsep,topsep=0pt,partopsep=0pt]
			 			\item Among is used for undifferentiated items.
			 			\item Between is used with individual, named items.
			 		\end{itemize}  & 
					\begin{itemize}[noitemsep,topsep=0pt,partopsep=0pt]
			 			\item She couldn't decide among all the halls.
			 			\item She couldn't decide between Swire or St John's.
			 		\end{itemize} \\ 
		 			
					\noindent \mbox{mutual} vs \mbox{reciprocal} &
					\begin{itemize}[noitemsep,topsep=0pt,partopsep=0pt]
		 				\item
		 				Mutual is used when more than one person has the same feeling/opinion as another towards a third party/object/concept etc.
		 				\item Reciprocal is used when two or more people feel, think or act in the same way about or to one another.
		 			\end{itemize}  & 
					\begin{itemize}[label=$\blacktriangle$,noitemsep,topsep=0pt,partopsep=0pt]
		 				\item `I disagree with the government's policy on carrots.' 
						\item[$\blacksquare$] `So do I. The feeling's mutual.'
		 				\item `I won't steal your cheese.'
						\item[$\blacksquare$] `I won't steal your cheese either. We have a reciprocal arrangement.'
		 			\end{itemize}\\
		 			
	 			
	 			\noindent \mbox{less} vs \mbox{fewer} &
				\begin{itemize}[noitemsep,topsep=0pt,partopsep=0pt]
	 				\item Less is used with nouns which are not countable objects: if you could use much to describe having a lot of the noun, use less.
	 				\item Fewer is used with countable objects: if you could use many to describe having a lot of the noun, use fewer.
	 			\end{itemize} & 
				\begin{itemize}[noitemsep,topsep=0pt,partopsep=0pt]
	 				\item `I can't eat that much cheese: please give me less.'
	 				\item `I can't eat that many sprouts: please give me fewer.'
	 			\end{itemize} \\ 
		 		
		 		
		 		\noindent 
		 		\mbox{effect} vs \mbox{affect} (verb) &
		 		\begin{itemize}[noitemsep,leftmargin=*,topsep=0pt,partopsep=0pt]
		 			\item Effect as a verb means to bring about, or to have the result that.
		 			\item Affect as a verb means to have an impact on or to change something; it also means to simulate something which is untrue.
		 		\end{itemize}  & 
		 		\begin{itemize}[noitemsep,leftmargin=*,topsep=0pt,partopsep=0pt]
		 			\item A glass of brandy may effect his recovery [bring his recovery about].
		 			\item A glass of brandy may affect his recovery [have an impact on whether he recovers].
		 			\item He affected to have drunk only one glass of brandy [when he had actually drunk more than one glass].
		 		\end{itemize} \\ 
		 		
		 		\noindent 
		 		\mbox{effect} vs \mbox{affect} (noun)
		 		 &
		 		\begin{itemize}[noitemsep,leftmargin=*,topsep=0pt,partopsep=0pt]
		 			\item Effect as a noun means the impact something causes.
		 			\item Affect as a noun means somone's outward appearance of their psychological state.
		 		\end{itemize}  & 
		 		\begin{itemize}[noitemsep,leftmargin=*,topsep=0pt,partopsep=0pt]
		 			\item The storm had wide-reaching effects.
		 			\item His affect was one of cheerful indifference.
		 		\end{itemize} \\ 
		 		
		 		
		 		\noindent 
		 		\mbox{infer} vs \mbox{imply}
		 		&
		 		\begin{itemize}[noitemsep,leftmargin=*,topsep=0pt,partopsep=0pt]
		 			\item Infer is to read a meaning into a statement which has not been explicitly stated: to read between the lines.
		 			\item Imply is to suggest something without explicitly stating it: to hint at something (usually something negative).
		 		\end{itemize}  & 
		 		\begin{itemize}[noitemsep,leftmargin=*,topsep=0pt,partopsep=0pt]
		 			\item 
		 			He told me that these one-size-fits-all gloves fit most people's hands. I inferred that he thought my hands were too big, and resented what he was implying.
		 		\end{itemize} \\
	 		\bottomrule
			\end{longtable}
			}

			\section{Spelling}
			\subsection{General guidelines}
			Use suffix -ise/-yse/-isation not -ize/-yze/-ization. We prefer `-ise' as it is more common in British usage and requires fewer exceptions.
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item Derren Brown hypnotised his subject live on TV.
				\item They didn't receive authorisation to take the trip.
				\item[\xmark] She wished she had organized her books alphabetically.
			\end{itemize} \end{mdframed} }
			Retain -e where required for pronunciation: ageing/acknowledgement. This rule is sometimes known as the `magic e' rule.\par
			Contractions: use of `hasn't' rather than `has not' etc is fine in the majority of cases, especially informally.
			\subsection{Foreign spellings}
			For non-technical, laymen terms archaically spelt with `ae', just use `e' spellings, not ae or æ.
			{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
				\item encyclopedia
				\item medieval
			\end{itemize} \end{mdframed} }
			Technical words (scientific Greek- or Latin-root words) that have æ do not retain the ligature, but they are spelt with ae nonetheless. 
				{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
					\item archaeology
					\item haematology
					\item orthopaedics
				\end{itemize} \end{mdframed} }
			Use accents and different letters in foreign words (ø, ç, capitalisation for German nouns etc) only when:
				\begin{itemize}
					\item a word is still considered foreign and has not (yet) been absorbed into English
					\item they are required to differentiate from another word (in English or the source language)
					\item they are required as part of the name of a person, place, book etc.
				\end{itemize}
				Diacritics are often left out in commonly used words for the ease of typing. You can choose to omit the diacritics if this does not cause ambiguity.
				{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
					\item elite
					\item[\xmark] élite
					\item résumé [CV]
					\item resume [to start again]
					\item café
					\item cafe
				\end{itemize} \end{mdframed} }
			\subsection{Plurals}
				Use appropriate foreign (particularly ancient Greek and Latin) plural forms where still in common usage (also see \textbf{alumna/ae/i/us} below).
				{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
					\item nucleus → nuclei
					\item stratum → strata
					\item genus → genera
					\item analysis → analyses
					\item basis → bases
					\item crisis → crises
					\item phenomenon → phenomena
					\item bacterium → bacteria
					\item millennium → millennia
				\end{itemize} \end{mdframed} }
				Note that more than one plural form is sometimes in use for different meanings of a word.
				{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\warningmark]
					\item formula → formulas \textbf{but} formulae in maths/chemistry
					\item index → indices for maths \textbf{but} indexes for books
					\item appendix → appendices for books \textbf{but} appendixes in anatomy
					\item medium → media \textbf{but} mediums for spiritualists
					\item datum → data in technical cases \textbf{but} points of data in everyday use
				\end{itemize} \end{mdframed} }
				Proper names ending in -y do not change to -ies if pluralised.
				{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
					\item One of the most popular stories in Bunty was `The Four Marys'.
				\end{itemize} \end{mdframed} }
				With compound words formed by a noun and an adjective, or two nouns connected by a preposition, pluralise the (more important) noun. This is often the `head' noun.
				{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
					\item Attorney General → Attorneys General
					\item brother-in-law → brothers-in-law
					\item passer-by → passers-by
					\item gin and tonic → gins and tonic
				\end{itemize} \end{mdframed} }

				\chapter{Miscellaneous}
				\section{Personal pronouns}
					\textbf{I} is always the subject of the verb and \textbf{me} is always the object.
						{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
							\item I cooked lunch.
							\item He cooked lunch for me.
						\end{itemize} \end{mdframed} }
					This doesn't change if there is more than one subject or object in a sentence.
						{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
							\item Pete and I cooked lunch.
							\item He cooked lunch for Pete and me.
						\end{itemize} \end{mdframed} }
					If you are unsure whether to use \textbf{I} or \textbf{me} in this kind of sentence, try it without the other person's name and it will be clear which to use.
						{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
							\item He gave top marks to Serena, Keith and me. → He gave top marks to me.
							\item[\xmark] He gave top marks to Serena, Keith and I. → He gave top marks to I.
						\end{itemize} \end{mdframed} }
					\subsection{Myself, yourself etc}
					All pronouns ending in -self or -selves are reflexive pronouns and are used only to refer back to the subject of the sentence. They can never be subjects of a sentence themselves.
						{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
							\item I treated myself to a new set of speakers.
							\item Mordecai takes himself very seriously.
							\item Where do you see yourself in ten years' time?
							\item Theresa and I googled ourselves and didn't like what we found.
							\item[\xmark] Cassandra and myself crossed the road.
						\end{itemize} \end{mdframed} }
					Never use any of these pronouns as a more polite or formal way of addressing people, or if the subject of the sentence is different from the reflexive object (eg I must always be paired with myself).
						{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
							\item[\xmark] If you have any questions, please contact Professor Plantaganet or myself.
						\end{itemize} \end{mdframed} }
					\section{Plural or singular?}
						Use singular verbs for describing faculties, teams, groups etc.
						{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
							\item The faculty has voted to keep the building open.
							\item  The HKU Dragon Boat Team has won the 2018 International Dragon Boat Festival World Cup.
						\end{itemize} \end{mdframed} }
						To disambiguate when talking about the individuals who make up a group, use `the members of' or `each member of'.
						{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
							\item The members of the faculty are mostly absent during holidays.
							\item Each member of the faculty has an email address.
						\end{itemize} \end{mdframed} }
					\section{Address, phone numbers, website etc}
					\subsection{URLs}
					Omit \texttt{http://} unless the URL does not begin with \texttt{www} and omit any trailing slash at the end of the URL, unless the URL does not work without it -- check before you omit (but ensure that any links in online documents retain the \texttt{http://} so that they point to the correct place).\par
					For secure websites, include the \texttt{https://}\par
					Use a typewriter or monospaced font if possible.
						{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
							\item\texttt{www.fb.com/lingsochku}
							\item \texttt{https://hku.hk/publications/7695}
							\item[\xmark] \texttt{www.fb.com/lingsochku/}
							\item[\xmark] \texttt{https://hku.hk/publications/7695/}
						\end{itemize} \end{mdframed} }
					\subsection{Referring to webpages}
					Only capitalise the first word (and any proper nouns), but consider instead using the actual URL for disambiguation in print or hyperlinking the descriptive text. \textbf{Never} change the capitalisation within a URL as it may cease to work. Leave out the full stop if the URL ends the last sentence of the paragraph.\par\newpage
					Make sure all hyperlinks are properly configured. It is common for hyperlinks to fail because punctuations eg full stops are accidentally included in the URL.
					{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
						\item For the latest ongoing research, please see the Department website's Research page.
						\item For the latest ongoing research, please see 
						\\ \texttt{https://www.linguistics.hku.hk/research/labs}
						\item For the latest ongoing research in the Department, please see  \texttt{https://www.linguistics.hku.hk/research/labs}. You can also find a list of researchers there.
						\item[\xmark] For the latest ongoing research in the Department, please see  \texttt{https://www.Linguistics.hku.hk/research/labs/}
						\item[\xmark] For the latest ongoing researchin the Department, please see  \texttt{https://www.linguistics.hku.hk/research/labs}.
					\end{itemize} \end{mdframed} }
					\subsection{Email addresses}
					These are case sensitive in the part before the \texttt{@}: \texttt{lingsoc@hku.hk} is not the same as \texttt{Lingsoc@hku.hk}. In practice, the majority of ISPs ignore this distinction, but consider carefully whether to use uppercase if required to avoid ambiguity (eg between lower-case l and number 1). In case of ambiguity, consider using another font.
					\subsection{Phone numbers}
					Using spacing between parts of numbers (international code, phone number) to make it easier to read.
					{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
						\item To contact us, ring John on 1234 5678.
					\end{itemize} \end{mdframed} }
					Include international code for international publications (eg +852).
					{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
						\item To contact us, ring John on +852 1234 5678.
					\end{itemize} \end{mdframed} }
					For local/internal publications, give extension numbers and include in brackets the number to dial from outside the University phone network.
					\subsection{Street addresses}
					Give full address when writing to a primarily non-HKU audience (naming the campus allow people to find buildings more easily online).
					{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
						\item The event takes place in Rayson Huang Theatre, Main Campus, The University of Hong Kong.
					\end{itemize} \end{mdframed} }
				\newpage
					If writing for an HKU audience, the name of a well-known building is enough on its own.
					{\firasans \begin{mdframed}[backgroundcolor=aliceblue] \begin{itemize}[label=\cmark]
						\item The event takes place in KK101, K.K. Leung Building.
					\end{itemize} \end{mdframed} }
