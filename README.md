# Linguistics Society, AA Branding Portal

Welcome to the Linguistics Society, AA Branding Portal! This repository contains the complete branding resources, guidelines, and tools for the Linguistics Society.

## 🌐 Access the Portal

**👉 Visit the branding portal at:** <https://awcaxttrgr.github.io/lingsoc_aahkusu-branding/>

This is the primary interface for all branding resources and tools.

## ✨ Key Features

### 📋 **Logotype Selector**

An interactive step-by-step tool to find the perfect logotype variant:

- **Version selection**: Choose between 2024 (Arts Association), 2024 (AA), 2021 (AAHKU), or Legacy (AAHKUSU)
- **Arrangement**: Select between Primary (Horizontal) or Secondary (Vertical) layouts
- **Language**: Choose English, Chinese, or Bilingual versions
- **Color variants**: Full color, negative (dark backgrounds), greyscale, or monochromatic
- **Session options**: With or without session information
- **Live previews** of your selections before downloading
- **Direct downloads** in multiple formats (PNG, SVG, PDF, EPS, AI)

### 📚 **Visual Identity Manual**

- Access comprehensive guidelines on correct usage of the society identity
- Color and placement rules with visual examples
- Brand standards and best practices

### 💾 **Download Resources**

Complete library of branding assets:

#### Manuals

- Visual Identity Manual (2025 Aug) - Latest version
- Style Guide (2019 Jan) - Written communication guidelines
- Quick Reference (2025 Aug) - Condensed quick guide
- Archived manuals for legacy versions

#### Font Files

- Andika IPA_LingSocAAKHUSU - For IPA typesetting
- Fira Sans - Latin text typeface
- Source Han Sans HC / Noto Sans Hong Kong - Traditional Chinese (HK)
- Charis - Serif Latin typeface
- Source Han Serif HC / Noto Serif Hong Kong - Serif Traditional Chinese (HK)

#### Icons & Graphics

- Directional icons (upstairs, downstairs)
- Transportation icons (lift/elevator, escalators)
- Informational icons (enquiries)
- All available in SVG format

#### Letterhead Templates

- AA Letterhead templates in portrait and landscape orientations
- MS Word DOTX format for easy customization

## 📖 How to Use

1. **Visit the portal**: Go to <https://awcaxttrgr.github.io/lingsoc_aahkusu-branding/>
2. **Use the Logotype Selector**: Answer a few questions about your needs to find the right logo variant
3. **Download assets**: Get your selected logotype in your preferred format
4. **Review guidelines**: Check the Visual Identity Manual for proper usage rules
5. **Explore resources**: Browse available fonts, templates, and icons

## 📝 Notes

- This site was ported from Google Sites in 2021 due to the migration of HKU Connect from Google to Microsoft
- All logo files are organized by version and file format for easy access
- The repository follows a consistent naming scheme for all branding assets
